# Site de uma página

1. Ler a casa do cliente (um arquivo com serviços, tom, regras).
2. Escrever um index.html único, mobile primeiro.
3. Publicar: `npx wrangler deploy --assets site --name NOME --compatibility-date 2026-09-01` (conta Cloudflare do dono).
Exemplo real: site de consultório fictício publicado em 1min15.
