# Conversa vira post

1. Leia a conversa, a transcrição ou o áudio transcrito inteiro.
2. Separe só o que o DONO disse. Tire: frases de impacto (literais), perguntas que o cliente fez, viradas de chave.
3. Proteja terceiros: nunca nome, número, faturamento, problema pessoal ou o nome do cliente do cliente. Troque por "uma cliente", "um mentorado".
4. Para cada achado bom, proponha um post: frase de impacto → post de frase; pergunta do cliente → carrossel de resposta; história → roteiro de reel.
5. Liste os achados numerados e pergunte quais escrever:

```opcoes
- Escreve todos
- Só os 2 melhores
- Me mostra as frases primeiro
```
